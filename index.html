데모

손동작 인식

2D를 3D로 만드는 경로는 두 개입니다. A 실루엣 경로는 분할된 캐릭터의 외곽선에 두께를 계산해 입체로 만듭니다. AI 모델 없이 기하 계산만 하기 때문에 브라우저에서 바로 돌고, GPU가 없는 PC나 인터넷이 없는 발표장에서도 동작합니다. draw2world-ai와 demo-3d-moving에서 구현했습니다. 형태가 단순하다는 한계가 있고, 생성 AI보다 품질이 좋다고 주장하지 않습니다. B 생성 AI 경로는 학습된 모델이 보이지 않는 면까지 추론합니다. FreePJT_idea에서 Era3D 6뷰, CharacterGen 4뷰 다중 시점 2D 이미지까지 만들었습니다. 다중 시점 2D 이미지는 아직 3D 메시가 아니며, 메시 재구성은 진행 중입니다. 막혔던 지점: CharacterGen이 실행 환경 오류로 돌지 않았고, 원본 경로를 미러 경로로 바꿔 2D 출력에 성공했습니다. 1회 39분 51초가 걸렸는데, 이건 2D 단계만의 시간입니다. [화면: 실루엣 3D 결과(demo-3d-moving), CharacterGen 4뷰 출력(FreePJT_idea) 캡처를 넣는다] Pinch Tower 데모입니다. [발표 메모 추가]

데모: 관절 적용

자동관절 인식 및 적용

두 번째 기술은 관절입니다. 먼저 분명히 해 둘 점이 있습니다. 지금 구현한 것은 3D 메시를 자동 리깅하는 것이 아니라, 그림의 실루엣에서 규칙으로 관절 위치를 추정하는 방식입니다. 생성 AI가 만든 3D 메시의 자동 리깅은 별도의 향후 과제입니다. 흐름은 실루엣 마스크를 받아 거리 변환과 형태 규칙으로 관절을 찾고, 스키닝으로 메시를 관절에 연결해 걷기·달리기 애니메이션을 만듭니다. 실패 1: 움직이면 얼굴과 몸이 늘어났습니다. 자세 기준 회전, 체형 가중치, 머리 회전 제한을 넣었고, minigame v2 문서에는 변형률이 25.6%에서 4.9%로 줄었다고 기록되어 있습니다. 다만 시험 조건 확인이 필요하고, 이 개선은 아직 데모에 병합되지 않았습니다. 저장소별로 결과가 다릅니다. 실패 2: 토끼 그림에서 귀를 머리로, 꼬리를 머리 방향으로 잡았습니다. 거리 변환과 형태 규칙을 고쳤지만, 다른 그림에서도 되는지는 아직 검증하지 않았습니다. [화면: 각 Before/After 자리에 팀원 저장소 캡처를 넣는다]

데모: 손동작 인식

손가락 대운동회

세 번째 기술은 실시간 동작 인식입니다. 웹캠 영상은 사용자 PC 안에서만 처리하고, 게임에는 동작 결과만 넘깁니다. MediaPipe로 손 21점, 몸 33점 랜드마크를 뽑고, 필터로 안정화한 뒤 제스처를 판정해 게임 입력으로 바꿉니다. motion-playground 저장소의 프로토타입입니다. 막혔던 지점은 조작 대상이 흔들리고, 양손이 같은 대상을 잡아 충돌하는 문제였습니다. 최근 대상 유지, 랜드마크 필터, 손별 소유권을 넣어 해결을 시도했습니다. 다만 개선율은 아직 측정하지 않았습니다. JS 테스트 198개가 통과했지만, 이건 합성·모의 데이터 기준입니다. 실제 사람 손 데이터 검증은 다음 단계입니다. [화면: motion-playground 실행 캡처 또는 짧은 영상을 넣는다]

데모: 손동작 인식

F1 레이싱 게임

이제 실제로 보여드리겠습니다. 그림을 그리고, 3D 캐릭터로 만들고, 관절이 들어가 걷는 것을 확인한 뒤, 웹캠 앞에서 손과 몸으로 조종하고, 미니게임까지 이어 갑니다. 정확히 말씀드리면, 지금은 각 단계를 개별 저장소의 데모로 보여드립니다. 하나로 이어진 통합 시연은 다음 목표입니다. 시연이 실패할 경우를 대비해 녹화본을 준비하고, GPU와 인터넷 없이 브라우저에서 도는 실루엣 경로를 백업 데모로 씁니다. [준비: 라이브 데모 순서, 각 저장소 실행 URL, 백업 녹화본 / 통합 시연 가능 여부를 팀과 확인]

내 몸짓을 따라 게임 속에서 활동한다.

마지막으로 로드맵입니다. 다음 단계는 기능을 더 붙이는 것이 아니라 통합입니다. 지금은 7개 저장소에 개별 데모가 있습니다. 1단계에서 대표 파이프라인을 설계하고, 2D→3D·리깅·동작 인식 후보를 같은 입력으로 비교해 핵심 오픈소스를 고르고, 베이스라인을 잽니다. 2단계에서 하나의 서비스로 통합하고 Before/After로 다시 잽니다. 그다음이 온라인 대전 게임입니다. 대결 코드는 있지만 다중 기기 검증 전이라 완성된 기능이 아닙니다. 마지막으로 같은 엔진을 말로 꾸미기, 3D 프린팅, 레이싱, 오픈월드로 넓힙니다. 레이싱은 별도 저장소의 확장 실험이며 핵심 서비스와 아직 연결되지 않았습니다. 정리하면, Draw2World AI는 그림을 살아 움직이는 캐릭터로 만드는 AI 플랫폼이고, 저희는 지금 2D→3D, 관절, 동작 인식이라는 세 가지 기술 난제를 풀고 있습니다. 감사합니다.

“구현 완료”도 개별 저장소 기준이며, 전체 흐름이 하나로 통합된 것은 아니다. 3D 캐릭터 변환 — 규칙 기반은 실루엣 볼륨 생성(브라우저), 생성 AI는 Era3D·CharacterGen 다중 시점 2D 출력까지 실험, 3D 메시는 미완료. 동작 인식 조종 — MediaPipe 손 21점·몸 33점 → 필터 → 제스처 → 게임 입력 (개별 저장소). 온라인 대결 — PeerJS/WebRTC 코드 존재, 다중 기기 검증 필요. 말로 꾸미기 — 로컬 LLM이 자연어를 구조화 명령으로 변환 (후순위).
